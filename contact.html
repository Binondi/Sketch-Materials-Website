Yes! Sketch Materials is completely free to download and use. All resources including Java codes, custom blocks, local libraries, and Lottie animations are available at no cost. We believe in making development tools accessible to everyone.

To install custom blocks, open Sketch Materials and browse the Custom Blocks section. Select the block you want to use and tap the download button. The block file will be saved to your device. Then, open Sketchware Pro and import the block file through the block manager. The custom block will be ready to use in your projects.

Absolutely. Sketch Materials is completely safe to use. The app does not collect any personal data, and all resources are verified before being made available. The app is open-source and the source code is available on GitHub for anyone to review. You can download it with confidence.

Sketch Materials is designed to work with the latest versions of Sketchware Pro. We recommend using the most recent stable release for the best compatibility. Most Java codes and custom blocks are compatible with Sketchware Pro 6.3.0 and above. If you encounter compatibility issues, please report them on our GitHub repository.

If you encounter a bug, you can report it by creating an issue on our GitHub repository. Please include a detailed description of the issue, steps to reproduce it, your device model, Android version, and Sketchware Pro version. You can also reach out to us via email at borthakurbinondi@gmail.com.
