# Sketch Materials - Official Website

The official website for **Sketch Materials**, a comprehensive toolkit Android app built for Sketchware Pro developers by Binondi Borthakur.

## 🚀 Features

- **Modern Dark UI**: Designed with glassmorphism effects, gradient text, and smooth animations.
- **Responsive Layout**: Works seamlessly across mobile, tablet, and desktop devices.
- **Typed.js Integration**: Dynamic animated headlines on the hero section.
- **Interactive Counters**: Animated statistics for Java codes, custom blocks, libraries, and animations.
- **Interactive FAQ Accordion**: Expandable Q&A section on the contact page.
- **Contact Form**: Direct mailto integration for quick outreach.
- **Comprehensive Legal Pages**: Full Privacy Policy and Terms & Conditions.

## 📄 Site Structure

```
├── index.html          # Main landing page (hero, features, how it works, stats, CTA)
├── about.html          # About page (mission, story, developer profile, offerings)
├── contact.html        # Contact page (form, info cards, FAQ accordion)
├── privacy-policy.html # Privacy Policy (data handling, third-party services, COPPA)
├── terms.html          # Terms & Conditions (license, restrictions, warranties, liability)
├── styles.css          # Main site styles (nav, hero, features, footer, responsive)
├── pages.css           # Sub-page styles (cards, forms, FAQs, developer profile)
├── logo.png            # App logo
├── java.png            # Java feature icon
├── block.svg           # Custom block feature icon
├── library.svg         # Library feature icon
├── animations.svg      # Lottie animation feature icon
└── menu.svg            # Mobile menu hamburger icon
```

## 🛠️ Built With

- **HTML5 & CSS3** (Vanilla, no heavy frameworks)
- **Poppins** font from Google Fonts
- **Font Awesome 6** for icons
- **Typed.js** for typing animations
